# Sharpy

[Sharpy](https://getsharpy.com) is an AI to-do list for Mac. It reads your Slack messages, email, calls and the text on your screen, and writes down what you were asked and what you promised, each task linked to the message it came from. When you send the reply or the pull request merges, Sharpy crosses the task off. Each morning it proposes the order of your day.

On a task, Sharpy can hand the work to Claude Code or Codex with a brief written from what it knows. The agent works in its own branch and opens a pull request for you to merge.

Claude Code, Codex, Cursor and the ChatGPT desktop app read and update your list through Sharpy's local MCP server: [sharpy-mcp](https://github.com/SharpyHQ/sharpy-mcp).
